Here are the methods to change the committer:
Temporary Override (Before Commit): Run the following command to explicitly set the author for the next commit:
GIT_AUTHOR_NAME="Your Name" GIT_AUTHOR_EMAIL="your@email.com" git commit -m "Message".
Modify Last Commit: Use git commit --amend --author="New Name <email@example.com>" --no-edit to correct the committer of the immediately preceding commit.
Configure Git Globally: Change your permanent git settings using:
git config --global user.name "Your Name"
git config --global user.email "your@email.com".
For git-gpt-commit users: If using git-gpt-commit, the tool uses your local git config, so changing the global or local config (as above) will change the committer. "
